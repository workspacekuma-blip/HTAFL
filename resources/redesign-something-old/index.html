create / Self-guided prompt

Redesign something old.

Give an existing object or garment a fresh perspective.

What you need

Paper, a pencil, or an existing item and materials you already have.

Try this

  • Choose something you already own.
  • Sketch a small change before working on the item.
  • Try a low-risk change. Ask for help with unfamiliar tools.

Make it your own

You can simplify, adapt or keep this practice private. Pause or choose another starting point whenever you like.

Optional reflection

What did you notice while making or participating?
